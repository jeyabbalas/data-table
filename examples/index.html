data-table examples

Ten single-feature examples for @jeyabbalas/data-table. Each one imports the package the same way a real consumer would.

  1. 01 — Minimal — smallest mount: eight rows defined inline in the .ts file, no network.
  2. 02 — Load from URL — 100 K-row NYC taxi fetch with a live progress bar.
  3. 03 — Programmatic filters — card / fare / tip / distance filters on NYC taxi; log filterChange.
  4. 04 — Derived columns — tip_pct expression + is_airport vector on NYC taxi.
  5. 05 — Event listeners — split panel: Observe listens via on(), Drive mutates via actions.*.
  6. 06 — Custom theme — terracotta / cream palette; light + dark fully recolored.
  7. 07 — i18n (French) — French UI chrome paired with a French-native wine fixture.
  8. 08 — Custom visualization — US-states choropleth on a custom state column; Observable Plot + us-atlas.
  9. 09 — Multi-table — two tables sharing a FilterPresetManager and a SessionStore; save a preset in A, load it in B.
  10. 10 — Filter presets — save the current filter set with a name; export all presets to JSON, import them back.
