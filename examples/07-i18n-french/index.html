07 Table en français

Code source ↗
Scénario : un outil interne chez un caviste français. Chaque bouton, menu, info-bulle et ligne de statut est en français — ouvrez un filtre de colonne, la boîte d'export ou les préréglages pour vérifier.
English Scenario: an internal tool at a French wine merchant. Every button, menu, tooltip, and status line reads in French — open a column's filter panel, the export dialog, or the presets panel to check. The whole translation is a single messages object passed to createDataTable(); see fr.ts.
