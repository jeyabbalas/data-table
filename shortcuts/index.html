Keyboard shortcuts

The table is a single stop in the page's Tab order. Tab into it, or click a cell, and a cursor appears that the arrow keys move; Tab again leaves the table. Everything below works with the keyboard alone, and the mouse gestures are listed with it.

Moving around

↑ ↓ ← →
Move the cursor one cell
Home End
First or last column of the row
Ctrl + Home End
First or last cell of the table
Page Up Page Down
Up or down one screen of rows
↑ on the first row
Move onto the column headers
Esc
Remove the cursor
Tab Shift + Tab
Leave the table

Selecting and copying rows

Enter
Select or deselect the cursor's row
Click a row
Select only that row; click it again to deselect it
Ctrl + click
Add a row to the selection, or remove it
Shift + click
Select every row from the last one you picked
Ctrl + C
Copy the selected rows, with their headers, as tab-separated text

Sorting and column headers

With the cursor on a column header.

Enter or Space
Sort by the column: ascending, descending, then off
Shift + Enter
Add the column to a sort on several columns
Ctrl + click ⇅
The same with the mouse, on the column's sort button
F2
Reach the header's buttons: pin, hide, filter, sort
← →
Previous or next button, once there
Esc
Back from the buttons to the cursor

Resizing and moving columns

Press Shift + F2 on a column header, then:

← →
Narrower or wider, 16 pixels at a time
Shift + ← →
Move the column left or right
Home End
Narrowest or widest
Shift + Home End
Move to the first or last place it can go
Backspace
Back to the default width
Enter
Keep the changes
Esc
Put the width and position back
Drag ⠿
Move a column with the mouse, by its grip
Drag the right edge
Resize a column; double-click the edge to reset its width

Charts in the headers

Click a bar
Filter a histogram to that range of values
Drag across bars
Filter to the range you brush; drag the brush to move it
Double-click the brush
Clear it
Click a category
Filter to that value
Ctrl + click
Pick several categories
Esc
Clear the latest brush or pick

Lists, structs and JSON

F2 or double-click
Open a nested or JSON cell in the value inspector
↑ ↓
Previous or next item
→ ←
Expand or collapse an item, or step into it or out
*
Expand an item and all its siblings
Ctrl + C
Copy the item as JSON
Ctrl + Enter
Add the item as a column of its own
Esc
Close the inspector

Undo, filters and dialogs

Ctrl + Z
Undo a filter, sort, column change or new column
Ctrl + Shift + Z, or Ctrl + Y
Redo
Enter
Apply the value typed in a column's filter
Esc
Close a dialog or panel
Tab
Move through a dialog: the focus stays inside it

SQL editor

In SQL filters and in the expressions of new columns.

Ctrl + Space
Suggest columns and DuckDB functions
Enter
Take the suggestion
Ctrl + /
Comment or uncomment the line
Ctrl + Z
Undo typing

Filters, sorting and the column layout are saved in this browser and come back when you open the same dataset again. Clear session forgets them.
