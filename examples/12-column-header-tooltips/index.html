Column header tooltips (back)

About

table.actions.setColumnHeaderTooltip(column, content | string | null) attaches a library-rendered popover to the column-name span. The content is a structured object — title, description, and label/value items — never raw HTML. Every text leaf is rendered via .textContent, so the API is XSS-safe by construction.

  1. Click Set all to apply realistic JSON-Schema-style metadata to every meaningful column.
  2. Hover (or keyboard-focus) any annotated column-name span to open the popover.
  3. Try the per-column shape buttons to see the rich, enum, and string-shorthand variants in isolation.
  4. Try the XSS-safety demo to confirm injected HTML renders as literal text.

One-click setup

Mirrors how a downstream app applies schema metadata at startup: a single pass through a tooltip catalogue.

Per-column shapes

Each call clears its column first. value: string renders inline; value: string[] renders as wrapping chips (a natural fit for enums). A plain string input is shorthand for { description: string }.

Clear all

Pass null (or any input that normalizes to empty) to clear a column.

XSS-safety demo

Sets every text field to a string containing <img>, <script>, <iframe>, etc. Hover passenger_count — no alert fires; the popover renders the angle-bracketed text literally. The setter never accepts HTML; every string is rendered via .textContent.
