# Class: QueryError

SQL query failure at runtime (syntax, missing column, abort).

## Example

```ts
table.on('error', ({ error, source }) => {
  if (source === 'query' && error instanceof QueryError) {
    toast(`Query failed (${error.code}): ${error.message}`);
  }
});
```
