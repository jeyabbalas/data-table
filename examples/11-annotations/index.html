About

table.annotations marks rows, columns and cells as errors, warnings or info: each gets a tint, and a popover lists the annotations where you hover, grouped by scope.

  1. Click a scenario (A–E) to add a specific set of annotations.
  2. Hover or keyboard-focus an annotated cell or header to open the popover.
  3. Toggle the severity filter checkboxes to hide a severity's tints without changing the store.

Scenarios

Each scenario clears existing annotations first so they don't accumulate. Clear all empties the store directly.
